# Deadlock Detection and Analysis Lab

Full-stack interactive OS deadlock lab built with React + Express.

## Run

```bash
npm install
npm run dev
```

- Frontend: http://localhost:5173
- Backend: http://localhost:4000

## Features

- Dynamic Allocation/Request/Available matrix editing
- Deadlock detection with step simulation
- Resource Allocation Graph with Cytoscape
- Comparison mode (Detection/Prevention/Avoidance)
- Performance analysis charts
- Learning mode + experiment history
- JSON/PNG export
- Optional MongoDB persistence (`MONGODB_URI`)
